Municipal Recreation Programs — Power BI Analysis (2018)

## Project Overview

This project uses Microsoft Power BI to analyze municipal recreation program data from 2018. The objective is to examine seasonal scheduling patterns, compare recreation facilities, and evaluate planned program registration capacities.

The interactive dashboard provides a visual overview of recreation programming and supports data-informed decisions about scheduling and resource allocation.

Tools and Skills

- **Microsoft Power BI:** Interactive dashboards and data visualization
- **Data Analysis:** Descriptive statistics and comparative analysis
- **Data Visualization:** Bar charts, KPI cards, and detailed tables
- **Business Intelligence:** KPI development and facility benchmarking
- **Interactive Filtering:** Analysis by season, location, and program type

Key Performance Indicators

| KPI | Value |
| Total Program Records | 23,903 |
| Total Recreation Locations | 85 |
| Average Maximum Registration Capacity | 14.16 |

Dashboard Features

1. **Recreation Programs by Season:** Examines how recreation programming varies across seasons.
2. **Top Recreation Facilities by Program Count:** Identifies facilities with the highest number of program records.
3. **Average Program Capacity by Activity Type:** Compares planned registration capacities across program categories.
4. **Average Program Capacity by Facility:** Benchmarks average planned capacity across locations.
5. **Detailed Program Capacity Table:** Allows examination of individual records and unusually high capacity values.

Interactive filters allow users to explore results by season, facility, and program type.

## Business Questions

- How does recreation programming vary throughout the year?
- Which facilities offer the greatest number of programs?
- Which activity categories have higher planned registration capacities?
- How does planned capacity differ across recreation facilities?
- How can these findings inform future scheduling and resource planning?

## Data Limitations

Maximum registration capacity represents planned program capacity, not actual attendance or utilization. Consequently, this analysis does not establish participation rates, program demand, or facility occupancy.
